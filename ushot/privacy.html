Privacy Policy for 유샷 (ushot)

Last updated: October 14, 2026
Google Chrome Extension (Manifest V3)

유샷 (ushot) ("the Extension") is committed to protecting user privacy. This Privacy Policy explains how information is handled within the Extension.

1. Information Collection and Use

유샷 (ushot) does NOT collect, store, transmit, sell, or share any personal data, browsing history, or user information.

  • No Remote Data Collection: The Extension does not connect to any external analytics, tracking, or remote tracking servers.
  • Local Execution & Processing: Captured screenshots are processed entirely in the browser's local memory and saved directly to your local device via chrome.downloads API.
  • Local Configuration Storage: User preferences (e.g. image format, quality, capture settings) are saved strictly inside your local browser using chrome.storage.sync solely for extension functionality.

2. Permissions Justification

The Extension requests the minimum permissions required to perform its features:

  • storage: Used only to preserve user preferences (image format, quality options) across devices.
  • downloads: Used only to save captured screenshots directly to the user's local disk without server upload.
  • activeTab: Used to display the active status badge and interact with YouTube video elements when invoked by user action.
  • Content Scripts (https://www.youtube.com/*): Used solely to detect the YouTube player and inject the screenshot capture button onto the player controls.

3. Changes to This Privacy Policy

If this Privacy Policy is updated, the revised policy will be posted on this page.
